# Donjon & Dragon — Life Ops App

Télécommande D&D 3.5 pour fluidifier les parties.
Dashboard Joueur (mobile) + Dashboard MJ (desktop).

## Stack
- Frontend: React 18 + Tailwind CSS
- Backend: Node.js / Express
- Real-time: WebSocket
- Deployment: Docker + VPS Debian
